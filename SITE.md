# DealFlow AI — App & Marketing Site

DealFlow AI is a fully automated real estate wholesaling platform. The repo is a
**TanStack Start** app (React 19 + Vite + TanStack Router + Tailwind CSS v4 +
Neon serverless Postgres), served on **port 3000**.

## Layout

```
src/
  db.ts                    # callable Proxy → Neon `sql` tagged-template helper
  router.tsx               # createRouter with generated route tree
  routeTree.gen.ts         # generated by TanStack Router (do not hand-edit)
  components/
    Header.tsx             # navy/gold nav: Dashboard, Calculator, CRM, Contracts, Buyers, Sell menu
    Footer.tsx
    SellerLandingPage.tsx  # shared template for the 11 /sell/* landing pages
  lib/
    sms.ts                 # Twilio sendSms (graceful fallback when unconfigured)
    email-outreach.ts      # 5-step email drip (SMTP)
    outreach.ts            # SMS drip + bulk outreach
    outreach-dispatcher.ts # scheduled dispatch logic (cron endpoint)
    skip-trace.ts          # lead enrichment (phone/email lookup)
    click2mail.ts          # direct mail postcards
    postcard-templates.ts  # postcard copy templates
    lead-import.ts         # CSV parsing + column auto-mapping
  routes/                  # file-based routing (TanStack)
    index.tsx              # "/" — marketing homepage
    get-offer.tsx          # lead capture form → leads table
    thank-you.tsx          # post-submit confirmation
    calculator.tsx         # MAO/ARV deal calculator
    dashboard.tsx          # KPI pipeline stats (live DB + mock fallback)
    buyers.tsx             # buyer list + deal matching
    contracts.tsx          # contract generation (print via .font-serif)
    settings.tsx           # Twilio / SMTP / Click2Mail config status
    sell-fast.tsx          # PPC landing page (no chrome/header)
    sell/*.tsx             # 11 seller-situation landing pages
    crm.tsx                # 8-stage pipeline kanban (leads, SMS, mail, skip-trace)
    crm_.import.tsx        # /crm/import — CSV import with auto-mapping
    api/outreach/dispatch.ts  # cron endpoint for scheduled outreach
  styles/
    app.css                # Tailwind v4 entry + navy/gold tokens + contract print styles
  db/
    migrate.ts             # migration runner (idempotent, applied in filename order)
    migrations/            # 002..007 SQL migrations (leads, automation, sms, email, csv, mail)
public/                    # static assets (favicons, hero-banner.png, robots.txt, sitemap.xml)
serve.ts                   # production server: dist/client static + dist/server/server.js SSR on :3000
publish.sh                 # build + restart production server on port 3000
```

## Commands

- `bun install` — install deps (TanStack Start + React + twilio + neon)
- `bun run dev` — Vite dev server on port 3000 (hot reload)
- `bun run build` — `vite build` → `dist/client` + `dist/server/server.js`
- `bun run start` — run `serve.ts` (production server on port 3000)
- `bun run publish` — build and restart the production server
- `bun run src/db/migrate.ts` — apply DB migrations (needs DATABASE_URL)

## Design

- **Colors**: navy `#0A1628` (navy-900/800/700), gold `#C8A951` (gold-500/400/300)
  — tokens defined in `src/styles/app.css`
- **Typography**: system sans; contracts render in serif for print
- **Responsive**: mobile-first, Header collapses to mobile CTA

## Environment (server-side only)

- `DATABASE_URL` — Neon Postgres connection string
- `TWILIO_ACCOUNT_SID` / `TWILIO_AUTH_TOKEN` / `TWILIO_PHONE_NUMBER` — SMS
- `SMTP_HOST` / `SMTP_USER` / `SMTP_PASS` / `EMAIL_FROM` — email outreach
- `C2M_USERNAME` / `C2M_API_KEY` — Click2Mail direct mail

All integrations degrade gracefully (mock data / logged failures) when
unconfigured, so the app is always navigable.
